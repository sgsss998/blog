![](/images/blog/zhipu-is-terrifying-wechat-01.png)我的 claude code 套餐到期了，正好最近在忙着主业工作+日常简单事务都用 minimax2.7 的小龙虾替代了，所以就忘记续费智谱的 max 套餐了，结果今天一看——想买都已经买不到了。价格也一路上涨，我翻到 3 月份的价格记录，当时加上优惠和返点，包月成本大约在百元级。站内版不再公开私人账单截图。![](/images/blog/zhipu-is-terrifying-wechat-02.png)结果现在一看官网，已经 400 多了，而且想买还买不到。这个变化很能说明供需关系：当一个模型套餐的真实使用价值被市场发现后，价格、库存和购买门槛都会迅速变化。![](/images/blog/zhipu-is-terrifying-wechat-03.jpg)站内版不展示旧促销、转售或账号交易截图，只保留公开安全占位图：![](/images/blog/zhipu-is-terrifying-wechat-04.jpg)![](/images/blog/zhipu-is-terrifying-wechat-05.jpg)  
不得不感慨，市场在用脚投票，嘴上说着 glm 不行不行，和 opus 还有很大差距，背地里却偷偷买包月套餐。结合我自身的使用体验，opus 确实更好用（主要体现在对人类意图的理解能力上，工程能力其实几乎相当），但是 glm 胜在性价比极高，除了一些最最复杂的长链条任务需要交给 opus 来做，80～95% 的日常任务交给glm5.1 是完全能够胜任的，也就是说，glm5.1 的能力相当于八九成功力的 opus 4.6/4.7，然而价格却是人家的三分之一甚至更低，也难怪被抢爆了。  
所以，市场的眼睛是雪亮的，与其看一些抒发情绪的帖子，更要看市场真金白银用脚投票出来的结果。  
如果再给我一次机会，我愿意在去年年底的时候，就续费一整年的智谱 max 套餐！  
按我自己的使用体验，可以粗略分工：Claude Code + Opus 适合高难度长链条任务；Claude Code + Sonnet 稳定，适合日常工程；Claude Code + GLM 在成本和能力之间平衡得不错；OpenClaw + Minimax 适合中轻度自动化和长期本地流程；Gemini Pro 在科学、数学和长上下文任务上值得保留；Codex + GPT 更适合长程代码、网站和资料系统维护。这个排序不是绝对排名，只是按我自己的工作流给出的工具分工。
