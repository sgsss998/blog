千呼万唤始出来，微信开放官方接口接入小龙虾了！我花了五分钟配置完成。

超简单步骤：

第一步，在跑OpenClaw的设备上装插件。打开终端，一行命令：

npx -y @tencent-weixin/openclaw-weixin-cli@latest install

第二步，用微信扫码授权。插件装好后会自动弹二维码，用微信扫一下就完事了。需要更新最新版本的微信，在“我的”-“设置”-“插件”找到小龙虾插件再扫码终端中出现的二维码

没了，就这两步。

用起来什么感觉：微信直接跟AI聊，跟发消息一样，手机端完美支持，再也不用开电脑盯着了

现在我躺在床上、地铁上、蹲厕所，都能随时召唤我的小龙虾帮我干活。

真香。
